# 폐기된 측정 데이터

프로토콜 결함이나 측정 조건 오류로 **결론에 쓸 수 없다고 판정된** 원시 데이터를 둔다.
지우지 않는 이유는 폐기 판단의 근거 자체가 기록이기 때문이다.

`results/<machine-id>/` 트리 밖에 두는 이유는 두 가지다.

- 재측정이 같은 날짜에 이뤄지면 `results/<machine-id>/<날짜>/` 를 덮어쓴다
- `parse_results.py` 는 `rglob` 로 재귀 순회한다. 같은 머신 트리 안에 두면 폐기본이
  유효 데이터와 함께 집계되고, `machine_id` 가 같으므로 혼입 검사에도 걸리지 않는다

여기 있는 데이터는 리포트 생성에 넣지 않는다.

|---|---|
